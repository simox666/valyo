Les images proviennent de captures natives de 3420 × 2006 pixels physiques, recadrées
de 242 pixels en haut pour ne conserver que la page (3420 × 1764). La barre du navigateur
et les favoris ne sont pas livrés. Ces dimensions ne constituent pas une certification
de la taille CSS du viewport. Aucun montage ni maquette générée.

Données : trois publications marquées « DÉMONSTRATION », quatre comptes fictifs,
deux salons publics et un privé ; 54 messages initiaux dans le salon principal.
Les tests HTTP ont été séparés du jeu de démonstration avant la transmission.

L'ouverture des outils responsive a été tentée, mais les interactions suivantes et
les rechargements n'ont pas produit un état fiable dans le pilote. Les captures finales
obsolètes sont exclues. Le porteur a demandé de clôturer la tranche et de transmettre
à Claude : ni validation mobile, ni validation clavier du nouveau menu n'est annoncée.
