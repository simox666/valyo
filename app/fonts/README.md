# Polices locales

Polices variables distribuées sans modification avec leur licence SIL OFL 1.1, sous-ensemble
latin (français compris) servi par Google Fonts le 16 novembre 2026 (direction « Carnet de labo ») :

- Inter (`Inter-Variable.woff2`, `OFL-inter.txt`) : texte courant.
- IBM Plex Mono (`IBMPlexMono-500/600/700.woff2`, `OFL-ibmplexmono.txt`) : titres et logo, graisses fixes
  prises dans le paquet `@fontsource/ibm-plex-mono` le 25 novembre 2026.
- Martian Mono (`MartianMono-Variable.woff2`, `OFL-martianmono.txt`) : petites étiquettes, numéros.

Chargées via `next/font/local` dans `app/layout.tsx` : aucun téléchargement pendant `next build`.
